SafeCopy 技术支持

开始拷卡

在拷卡页左侧添加素材卡或源文件夹，在右侧添加另一块磁盘、NAS 或备份文件夹。点击任务列表上方的开始按钮。点击任务进度条右侧的箭头，可查看每个文件的拷贝和校验进度。

查看与导出报告

切换到「报告」，选择日期范围和要导出的任务。需要跨 Mac 同步时，可以在「设置 → 报告同步」使用 macOS 已登录的 Apple 账号启用 iCloud 同步。

重看使用引导

打开「设置 → 帮助与反馈 → 使用引导」，可以用示例数据体验添加路径、拷贝校验和导出报告。

反馈问题

请到 SafeCopy 的 GitHub 反馈区留言。请避免附上个人文件路径或含有个人信息的报告。
